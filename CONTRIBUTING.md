# Contribuir a Tinta Privada

1. Creá una rama desde `main`.
2. No agregues historias, exportaciones, registros, estados de Wrangler, modelos ni rutas personales.
3. Conservá el funcionamiento local y la separación respecto de Tinta Viva.
4. Ejecutá `npm run lint` y `npm test` antes de abrir un pull request.
5. Explicá el cambio, su motivo y cómo fue probado.

Los cambios de proveedor deben mantener la conexión detrás de una ruta local y no enviar contenido a servicios externos por defecto.
